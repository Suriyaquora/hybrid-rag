# Vel Pari — A One-Hour Documentary in Code

Open `index.html` in a browser and press **Begin**. No build step, no dependencies.

- 12 chapters, 68 timed beats, normalised to exactly **60:00**
- Procedural canvas landscapes (hills, Parambu peak, creeper & chariot, armies, parrots, fire, rain, map)
- Browser speech narration + generated Mohanam-style ambient music and war drums
- Controls: play/pause, ±30s, chapter jump, 10×/60× preview speed, fullscreen, narration/music toggles
- Test deep links: `index.html?t=1500` jumps to 25:00

See `EPIC_FILM_PLAN.md` for the multi-part pan-Indian film plan.

Story basis: Sangam poetry (Kapilar, Purananuru) and *Veera Yuga Nayagan Vel Pari* by Su. Venkatesan. Dramatised adaptation; legendary episodes are marked "tradition".
